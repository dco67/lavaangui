# Synthetic advanced-analysis examples

The 2,400 rows (1,200 per group A/B) are simulated, not real participant data. The CSV and eight .lvm model files are byte-for-byte copies of the contributor's teaching test kit. File names are retained for compatibility. `specifications.csv` records the single-group syntax and intended degrees of freedom. Copy the files into a writable directory before editing. The English installed guide (`doc/advanced-analysis.html`) explains the GUI steps and scope.

The reference script `reference-examples.R` uses only the native lavaan API and optional semTools. It prints fit tables, comparisons, exploratory score output and defined-parameter effect estimates. It is not an application test, and its explicit group-specific labels for effect definitions are for native R only. It does not use internal extension functions or change the data or models. If the package is installed, run `source(system.file("advanced-examples", "reference-examples.R", package="lavaangui"))`. From a source checkout, run `Rscript inst/advanced-examples/reference-examples.R` from the project root. The script also accepts a CSV path as its first command-line argument (Rscript only). Install semTools to run the ordinal invariance example. The six source-level acceptance suites, separately provided in tests/manual, are the formal regression tests.
